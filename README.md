# Semusim Sales & Customers Dashboard

## 📌 Project Overview
An interactive Power BI dashboard tracking sales performance, customer metrics, order quantities, and product distributions to drive data-informed business decisions.

## 🛠️ Tools Used
* **Power BI**: Data modeling, DAX measures, and visual design
* **Power Query**: Data cleaning and transformation
* **Excel / CSV**: Source dataset (`sales_data_sample.csv`)

## 📊 Key Insights & Features
* **Sales & Revenue Tracking**: Monitors total sales value, order counts, and deal sizes.
* **Customer Analytics**: Identifies top and bottom performing customers and geographic performance across countries.
* **Fulfillment & Logistics**: Tracks shipping status and product line performance.

## 📁 Repository Structure
* `Team Sync.pbix` - Interactive Power BI report file
* `sales_data_sample.csv` - Source dataset
